# Mechatronics Quiz App

## What it does
This is a simple multiple-choice quiz about Mechatronics. The program asks the user five questions, checks the answers and gives a final score and percentage.

## How to run it
Install Python 3, then run:

python mechatronics_quiz.py

## Sample output
WELCOME TO MECHATRONICS QUIZ

Your score: 5 out of 5  
Percentage: 100%  
Perfect score! You got everything correct!

## My own twist
The extra feature I added is that the program shows the correct answers for any questions the user gets wrong.

## What I learned
I learned how to use lists, loops, functions and if/else statements in Python. I also learned how to accept and check user input.
